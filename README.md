# AI-Powered Retail Analytics and Smart Offer Recommendation System

## Project Overview
This project uses Machine Learning and Exploratory Data Analysis (EDA) to analyse retail sales data, predict sales trends, and generate smart promotional recommendations.

## Features
- Retail Sales Prediction
- Exploratory Data Analysis (EDA)
- Smart Offer Recommendation System
- Inventory Optimization Strategies
- Interactive Streamlit Dashboard
- Business Insight Visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Plotly
- Streamlit

## Machine Learning Models
- Linear Regression
- Random Forest
- XGBoost

## Dashboard
The Streamlit dashboard provides:
- Sales insights
- Prediction analysis
- Product recommendations
- Business visualizations

## Dataset
Superstore Retail Sales Dataset
